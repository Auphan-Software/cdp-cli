## Startup: a separate managed-launch concern

Jarvis owns native arguments, role profiles, tools, hooks and renewal policy. cdp-cli owns
browser transport. A lean managed QA profile must preserve durable work-item/terminal tracking,
hooks, checkpoint recovery, exact model/effort and browser budgets. It must be opt-in and must
not change the generic browser-QA default globally.

Before another long benchmark, compare ordinary versus lean managed startup with two bounded
read-only workers: boot, observe, report; no invoice actions. Verify actual native arguments,
advertised tool/system context, first-request tokens, working hooks, no children or extra epochs,
model identity and complete native accounting. A database model label alone is insufficient.

## Compaction: retention before economics

Current cp-controller can start ordinary managed renewal before native compaction at the250k
setting. The actual zero-netting2056 run nevertheless recorded two native auto compactions
in one session. Changing only the window can affect both Jarvis reseeding and native behavior.
The100k attempt already thrashed before browser work; repeating it is not useful savings evidence.

Use the actual zero-netting compactions first: the final payment/transaction checks pass without
duplicate fiscal actions, but two malformed-call receipts lack profile attestation and summary
generation usage is absent from exported assistant iterations. This is successful business-state
retention, not a fully qualified cost comparison. Any additional drill should resolve a specific
remaining retention gap rather than repeat this evidence.

If needed after reducing startup overhead, run one bounded retention drill against an already closed
invoice. Require an actual native compact_boundary, a sealed checkpoint with payment/RQ and
cleanup obligations, fresh observation after compaction and no repeated fiscal action. Reload
actual bill pixels when verification needs them; summaries do not retain the original image.
That proves recovery only. Economics additionally requires comparable renewal policy and
complete summary-generation usage/native cost reports. If the managed path cannot provide
that control, leave compaction savings explicitly unproven rather than manufacture a long run.

Release decisions use cost per independently verified completion, with failures included.
API-equivalent costs do not represent a Claude Max subscription invoice. Controller costs
excluded by a worker-only comparison must remain explicitly identified.
