## Further cuts by next-action utility

The second pass removes repeated input kind/target keys, duplicated source/recovery
boilerplate, generic changed/stateRequested/detailsOmitted counters, healthy coverage
defaults, available/false diagnostic flags, and repeated historical expansion metadata
in observe omissions. Successful matched click witnesses retain trusted/type/match
and frame-delivery semantics without pointer coordinates or target tag echoes.
Failures and mismatches retain those details. Unavailable diagnostics, log limits,
unknown coverage values, incomplete readiness, alert/status/dialog controls, error
counts, refusal instructions and source-bound discovery remain visible.

Screenshot paths and original pixel dimensions are removed only after the MCP
bridge has successfully read and attached the image. Scale, displayed dimensions,
CSS coordinate frame and semantic alignment remain. Missing or oversized images
retain file recovery paths. Canonical evidence, explicit full output, historical
expansion and execution budget reporting are unchanged. Availability defaults are
omitted, not evidence that acceptance checks passed; diagnostic collection remains
bounded to the last100 records. Ordinary CLI output is unchanged.
